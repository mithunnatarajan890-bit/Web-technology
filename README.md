# 🚀 Lumora — Cadet Skyranger

An interactive, cinematic space-themed hero page built with **HTML, CSS, and Vani lla JavaScript**. The project features a fictional space cadet, a glowing planetary horizon, cursor-controlled head movement, and an animated glass helmet.

## ✨ Features

- 🌌 **Cinematic Space Background** — A glowing orange planetary horizon against deep navy space.
- 👨‍🚀 **Interactive 3D-Style Character** — A pre-rendered character with cursor-controlled head movement.
- 🪖 **Animated Glass Helmet** — Click the red **PUSH ME** button to toggle the helmet.
- 🖱️ **Custom Cursor** — A white cursor dot with a smooth trailing ring.
- 💡 **Glowing Typography** — A cinematic `SKYRANGER` headline with layered light effects.
- 🎬 **Entrance Animations** — Smooth animations for the logo, headline, captions, and button.
- 📱 **Responsive Design** — Includes mobile layout adjustments.
- ♿ **Reduced Motion Support** — Respects the user's reduced-motion preference.
- ⚡ **No Build Step** — Runs directly in a modern web browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Web Animations API
- HTML5 Video
- Google Fonts — Archivo and Urbanist

## 🚀 Getting Started

### Prerequisites

- A modern web browser, such as Chrome, Edge, or Firefox.
- An internet connection to load the remote images, video, and Google Fonts.
- Visual Studio Code (optional).

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/lumora-skyranger.git
   ```

2. Open the project folder:

   ```bash
   cd lumora-skyranger
   ```

3. Open `lumora_skyranger.html` in your browser.

   Alternatively, open the folder in VS Code and use the **Live Server** extension.

## 🎮 How to Interact

1. Move your mouse horizontally to control the cadet's head direction.
2. Click the red **PUSH ME** button to lower the glass helmet.
3. Click the button again to toggle the helmet off.
4. Watch the character's gaze drift gently when the cursor remains still.

## ⚠️ Notes

- The character, head-turn video, and helmet are loaded from remote media URLs.
- The head animation depends on video seeking and browser media support.
- If fetching the video as a blob fails because of network or CORS restrictions, the page falls back to the original video URL.
- The supplied media assets may have separate usage terms. Check their licensing before redistributing them.
- The project does not use a JavaScript framework or require a package manager.
